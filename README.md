## Overview
Lyrics used are from official sources, if there's no official ENG translation, I will try to find and use translations from the artists community. <br>
The .lrc files are created using Aegisub with waveform precision. Using MPV & Musicolet for double checking timings and styles.
<br>
<b>IMPORTANT:</b> This repository only provides synced timings. Lyrics sourced are credited and linked to their original owners.
<br> <hr>
Note:
* The timing for MusicBee (Windows10) is off depending on your audio output. I recommend adding offset depending on how delay the lyrics appears, this is a known issue on MusicBee v3.6.
* USE [offset:] '+' or '-' depending on the delay. NOTE: It uses millisecond
* Musicolet timings are correct, but using bluetooth adds delay, I recommend using speaker or wired earphones.
<br>

## Programs used:
* [Aegisub](https://github.com/arch1t3cht/Aegisub/releases) for syncing with waveform precision
* [MPV](https://github.com/mpv-player/mpv) for doublechecking timings and styling on PC
* [Musicolet](https://play.google.com/store/apps/details?id=in.krosbits.musicolet) for checking timings on Mobile
